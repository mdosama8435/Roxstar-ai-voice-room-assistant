# RoxStar AI Voice Room Assistant - Frontend Shell

A production-grade dark UI shell for the RoxStar AI Voice Room Assistant built with Next.js, React, TypeScript, and Tailwind CSS.

## Features (Phase 1)
- **RoxStar Design System**: Premium obsidian palette, violet/pink accent glows, glassmorphic cards, accessible typography.
- **Participant Grid**: 4 static participant cards (Rahul, Priya, AI Dost, AI Sathi) with support for all conversational states.
- **Tabbed Conversation Panel**: Conversation timeline, Text Chat, Events, and Analytics tabs.
- **Room Intelligence Panel**: Real-time inspection for Room Context, Speaker Memory, Dual-Bot Arbitration, and 7-stage voice pipeline.
- **Control Bar**: Disabled/unavailable controls for mic, speech, screen share, and message input.

## Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Type Checking
```bash
npm run type-check
```

### 3. Run Development Server
```bash
npm run dev
```

Navigate to `http://localhost:3000/room/demo`.
